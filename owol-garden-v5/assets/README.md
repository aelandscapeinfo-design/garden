# OWOL Garden V4 자산 기록

`registry.json`은 이번 실행본의 prototype을 실제로 생성해 측정한 치수/삼각형 기록입니다. 본체와 미술 윤곽선 삼각형 수를 구분합니다. near/far LOD를 모두 측정합니다.

미술 검토 범위는 나무·관목·그라스·초화와 재료/벤치입니다. 넓은잎 초본·흰꽃·지피는 기존 V3 표현이며 이번 미술 방향으로 재설계했다고 표시하지 않습니다. botanicalDataVerified는 false입니다.

전체 출처와 라이선스는 루트 ASSETS.md 및 THIRD-PARTY-NOTICES.txt를 확인하세요. 참고 이미지를 런타임 자산으로 사용하지 않았습니다.

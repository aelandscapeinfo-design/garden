검증일: 2026-10-16 UTC. 실제 빌드한 `release/OWOL-garden-v5.html`을 Linux Chromium의 HTTP 서버에서 실행했습니다. 화면은 WebGL 실행 결과이며 합성 시안이 아닙니다.

## 모바일 검사의 범위

Chromium의 **390 × 844 CSS px, DPR 2, touch/mobile 에뮬레이션**입니다. CDP 터치 이벤트로 실제 한 손가락 패치를 그리고, 두 번째 손가락으로 미완료 획을 취소하고, 완료한 획의 되돌리기·다시 실행·저장·복원을 확인했습니다. 패널 접기와 가로 넘침 없음, 적용 버튼이 화면 안에 있는지도 확인했습니다. 기존 카메라용 둘러보기 모드의 두 손가락 조작과 편집 분리를 검사했습니다.

실물 Android/iPhone, Safari, Windows 실행기의 더블클릭 동작은 **직접 시험하지 않았습니다**. 이 환경은 `file://` 열기가 관리 정책으로 막혀 있어 로컬 HTTP 실행을 검증했습니다. Node.js 24와 Chromium 기반 브라우저의 실행 방법을 제공합니다. 에뮬레이션 결과를 실제 휴대폰 성능 보장으로 해석하면 안 됩니다.

## 성능 실측

`evidence/performance-v5.json`, `scripts/measure-v5.mjs` 참조. 다른 브라우저 작업을 멈추고 두 빌드를 순서대로 한 번씩 측정했습니다. Linux, AMD EPYC 7763(할당 CPU 4개), Chromium 154.0.8037.57, **ANGLE SwiftShader 소프트웨어 렌더러**, 1440 × 960 창/1440 × 882 캔버스, DPR 1, 기본 품질, 같은 19개 요소와 카메라입니다. 24단계 실제 마우스 우드래그 동안 각각 26개 RAF 프레임을 관찰했습니다.

| 항목 | V4 | V5 |
| --- | ---: | ---: |
| 정지 장면 draw call / 삼각형 | 44 / 95,410 | 44 / 95,410 |
| 모델 prototype / geometry 수 | 9 / 61 | 9 / 61 |
| 텍스처 추정 바이트 | 2,097,168 | 2,097,168 |
| RAF 간격 중앙값 | 266.8 ms | 283.3 ms |
| RAF 간격 p95 | 550 ms | 750 ms |
| 중앙값 간격의 역수 | 약 3.75 fps | 약 3.53 fps |

이 CPU 소프트웨어 렌더링에서는 부드러운 실시간 성능을 달성하지 못했습니다. 단일 측정의 차이를 성능 개선/퇴보의 확정값으로 주장하지 않습니다. 실제 GPU·실물 휴대폰은 별도 측정이 필요합니다. 보고서의 pointermove→다음 RAF 콜백 간격은 표시 완료 지연을 측정한 값이 아닙니다.

포장은 면마다 하나의 메시와 world-meter shader로 표현하며 구멍은 실제 면 기하에 뚫립니다. 획 도중은 윤곽 프리뷰만 갱신하고 종료할 때 바뀐 면을 다시 만듭니다. 바닥의 소유 영역 변화에 따라 기본 흙 메시도 갱신하지만 식물 prototype은 재생성하지 않습니다. 최대 300개 요소·48개 면·전체 4,096개 꼭짓점은 데이터 검증 상한이며 이 최대치에서의 속도 보장이 아닙니다.

## 남은 제한

- 분리된 섬은 같은 논리 영역 ID의 MultiPolygon으로 저장합니다. 구멍/섬을 포함한 렌더·배치·면적·복원은 유지되지만, 섬마다 독립 ID를 만들어 따로 선택하는 기능은 남아 있습니다.
- 새 패치의 고급 제어점 편집은 제공하지 않습니다. V4 윤곽 데이터에 대한 기존 고급 편집은 유지합니다. 사각 드래그 채우기 별도 도구는 없고 사각/원형 연속 브러시를 사용합니다.
- 건물 위치는 수치 입력, 회전은 90° 단위입니다. 자유 CAD 드래그·내부·지붕 편집·별도 중정 치수 입력은 없습니다. ㄱ/ㄷ의 안쪽 공간은 외곽 치수와 날개 폭에서 계산됩니다.
- 출입 연결은 0.25 m 격자 기반 안내입니다. 법적 피난·접근성·시공 적합성 판정이 아닙니다. 출입문은 건물별 한 개입니다.
- 기존 벽·난간을 포함한 구성을 변환한 경우 그 고정 구조는 임의 이동/크기 변경하지 않습니다. 다른 치수는 기본 구성 카드에서 선택합니다. 자유 빈 땅은 중심 기준으로 치수를 바꿀 수 있습니다.
- 면을 이동하면 식물은 원래 좌표를 유지하고 새 영역 밖 요소는 대기함으로 갑니다. 식물까지 동반 이동하는 옵션은 없습니다.
- 경계의 '부드러운' 적용은 실제 꼭짓점을 다듬습니다. '정돈된'으로 바꾸는 것만으로 이전 기하가 복원되지는 않으며 되돌리기를 사용해야 합니다.
- 새 식물 모델 0개. V4 카툰 4유형, 보존한 V3 전용 3유형을 구분합니다. 실제 품종/생육 DB는 연결하지 않았습니다.
- 기존 버전은 다른 포트/주소에서 실행하므로 그 브라우저 저장소는 자동 공유되지 않습니다. V4에서 JSON을 내려받아 V5에서 가져오세요. V5에서 이전 버전 파일을 읽어도 원본을 덮어쓰지 않습니다.
- 브라우저 저장소 삭제·시크릿 창·다른 기기까지 복구하는 서버 저장은 없습니다. 중요한 정원은 JSON으로 함께 내보내세요.

실제 식재와 시공은 현장 조건과 전문가 검토가 필요합니다. 서버 상담 전송·개인정보 수집·결제·회원가입 기능은 없습니다.

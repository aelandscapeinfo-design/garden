# V5 저장 예시

앱의 `JSON ↑`에서 파일을 선택하면 전체 공간·배치·카메라를 불러옵니다. 현재 작업을 유지하려면 먼저 JSON을 내보내세요. 실제 부지 설계도나 생육 적합성 자료가 아닙니다.

- `empty.json`: 영역·건물·요소 0개의 빈 땅.
- `L-house.json`, `U-house.json`: 실제 브라우저에서 회전·반전·문을 수정하고 내보낸 건물.
- `patch-and-catalog.json`: 구멍 난 목재 포장과 식재 영역, catalogId를 가진 초화.
- `raised-planter.json`: 면 복제·합치기·이동·잔디 전환, 0.55 m 독립 플랜터와 식물.
- `L-garden.json`, `U-garden.json`: 기본 구성 카드에서 예시 식물을 함께 선택한 전체 장면. `review.html`의 실제 화면과 대응합니다.

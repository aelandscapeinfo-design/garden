# V6 자산 출처와 검증 범위

신규 식물: `src/plant-models-v6.js`의 직접 제작 절차 기하입니다. 외부 모델·사진·텍스처를 포함하지 않습니다. 수종별 형태 카드와 ID·학명 참고·권리·한계는 `src/plant-library-v6.js`, `evidence/catalog-v6.json`, CSV에 있습니다.

신규 재질: `src/surface-materials-v6.js`에서 직접 생성한 256 × 256 색/높이 맵입니다. 색은 sRGB, 높이는 선형 데이터, roughness 0.88–0.97, metalness 0, 세계 좌표 단위는 m입니다. 식재지 기본은 soil, mulch와 gravel은 명시적 선택입니다. 콘크리트는 별도 물리 재질이며 목재 결과 판 방향은 함께 회전합니다. 표면 높이 맵은 셰이딩용이고 보행면이나 뿌리 기준 높이를 변경하지 않습니다.

이전 교목·관목·그라스·꽃 및 물체는 V5 소스의 직접 제작 절차 모델을 보존했습니다. 이전 V3 전용 3개 형태를 신규 수종 수에 포함하지 않습니다.

참고 문서: NC State Extension Gardener Plant Toolbox, 2026-10-17에 12개 종별 페이지의 텍스트와 사진 목록을 확인했습니다. 글을 바탕으로 형태를 단순화한 개념 모델이며 특정 품종이나 실제 식물 데이터베이스가 아닙니다. 원본 사진 열기 두 건은 403 오류였고, 전체 전초·잎·꽃 사진 대조는 끝나지 않았습니다. 일부 참고 사이트의 본문은 접근 불가였습니다. 인증·차단을 우회하거나 사진을 배포 자산으로 사용하지 않았습니다.

종별 원문 URL은 카탈로그의 referenceUrls에 있습니다. 사진 자체의 라이선스가 혼합되어 있으므로 공개 접근 여부와 별개로 앱에 수록할 권리가 있다고 간주하지 않습니다.

새 의존성은 없습니다. V5와 동일한 three 0.186.1 / polygon-clipping 0.15.7 / Vite 8.3.4 및 Playwright 1.64.1을 사용합니다. 배포 시 third-party code notices를 패키지에 포함합니다.

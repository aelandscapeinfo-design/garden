# OWOL Garden V6 · 재질과 식물 형태 기준판

V5를 보존한 별도 V6 기준판입니다. 흙·포장과 12개 식물 형태의 실제 렌더 경로를 구현했습니다. **전체 V6 완성본이나 36종 납품본은 아닙니다.** 사진 대조 검수 및 36개 확장은 남아 있습니다.

## 소스 실행

```sh
npm ci --cache /tmp/owol-v6-npm
npm run dev
```

개발 서버는 5186, 빌드 후 `node scripts/serve.mjs`는 5186, 독립 실행 패키지 서버는 5187입니다. 기존 V5 개발 서버 5182와 분리했습니다. 이 브랜치는 코드와 파일 제공용이며 웹 서비스 배포를 포함하지 않습니다.

```sh
npm run build
npm run test:unit
npm test
node scripts/fixtures-v6.mjs
```

## 바뀐 동작

- 새 화단과 플랜터의 기본 표면은 노출 흙입니다. 바크와 자갈 멀칭은 별도로 선택합니다. 식재 가능 논리는 기존 영역 기하를 사용합니다.
- 일곱 재질은 독립된 색·높이 텍스처와 무광 물리 재질을 사용합니다. 세계 좌표 1 m 기준이며 면 크기를 늘려도 입자가 늘어나지 않습니다.
- 포장 재료·패턴·모듈·방향·줄눈·seed를 분리합니다. 콘크리트는 석재에 연결하지 않습니다. 부정형 판석은 닫힌 Voronoi 조각과 공유 직선 경계를 사용합니다.
- 목수국형, 일본조팝형, 옥잠화형, 휴케라형, 에키네시아형, 사루비아형, 아스틸베형, 억새형, 사초형, 홍지네고사리형, 큰꿩의비름형, 크리핑타임형의 원본 절차 기하를 추가했습니다. 각 3개 구조 변형이 있습니다.
- 기본은 잎 중심입니다. ‘새 식물의 표시’에서 꽃 보기를 고르면 이후에 배치하는 식물과 실제 모델 썸네일에 반영됩니다. 이미 배치한 식물의 상태는 저장한 대로 유지합니다.
- 새 식물의 자산 ID·버전·LOD·구조 변형·계절을 렌더 키로 사용합니다. seed는 개체별 미세한 색 편차에 사용하고 seed마다 별도 모델을 만들지 않습니다.

## 정확한 수량과 한계

| 항목 | 수량 |
|---|---:|
| 전체 식물 카탈로그 | 기존 7 + 신규 12 = 19 |
| 현재 V4 미술 프로필에서 배치 가능 | 기존 4 + 신규 12 = 16 |
| 신규 실제 자산 / 구별되는 형태 | 12 / 12 |
| 신규 구조 변형 | 자산당 3, 총 36 (수종 수가 아님) |
| 신규 단순 색상 변형 | 0 |
| 품종 재현 검수 완료 / 생육 DB | 0 / 0 |
| 36개 1차 목표까지 남은 신규 자산 | 24 |

모두 특정 품종을 보증하지 않는 형태 예시입니다. NC State Extension의 12개 참고 문서는 접근했지만, 원본 사진 두 건은 403으로 열리지 않았고 나머지 사진 정밀 대조는 미완료입니다. 일부 참고 사이트의 본문도 접근하지 못했습니다. 외부 사진·타사 메시·텍스처를 앱에 넣지 않았습니다. 식재 적합성·성숙 크기·일조·토양·내한성 값은 검증 전이므로 비워 두었습니다.

## 저장과 이전 데이터

- V6: `version:6`, `documentVersion:6`, `catalogVersion:2`.
- 기존 구성 기하 스키마는 5, 이전 고정 공간 스키마는 3으로 유지합니다.
- V6 저장 키: `owol-garden-materials-v6`, 복구 키는 `-recovery`입니다.
- 시작 시 V6 기록과 기존 V5 기록을 읽을 수 있으며 V5 저장 키에는 쓰지 않습니다. V2/V3/V4 JSON 가져오기도 유지합니다.
- `assetVersion`, `seed`, `seasonalState`는 엄격 검증과 JSON 왕복 대상입니다. 지원하지 않는 자산 참조는 원본 속성 그대로 대기함에 보관합니다.
- 면의 기존 `material / pattern / moduleM / direction`은 각각 재료 ID / 패턴 ID / 미터 모듈 / 도 단위 회전의 호환 필드입니다. 중복 별칭을 저장하지 않습니다. V6는 `surfaceMaterialId`(식재 표면)와 `jointWidthM`(줄눈 m)을 추가합니다.

## 확인할 자료

`examples/v6/`에 재질, 12개 표본, 잎 중심 표본, 실제 혼합 정원 JSON이 있습니다. 앱의 JSON 가져오기로 확인할 수 있습니다. `evidence/v6/`에는 실제 실행 화면과 왕복 검증 결과를 남깁니다. `evidence/catalog-v6.json`과 CSV는 형태 카드·자산 ID·참고 URL·권리·한계를 연결합니다. `VALIDATION.md`는 이번 실행 결과와 미검증 사항을 구분합니다.

빈 땅·기본 맵·면 브러시·구멍·분리 면·건물·대기함·undo/redo·저장·JSON/PNG·마우스/터치 카메라의 기존 경로를 유지했습니다. 실제 기기 성능과 사진 수준의 식물 재현은 검수 완료로 주장하지 않습니다.

패키지를 다시 만들 때는 `npm run package`, `node scripts/review-v6.mjs`, `python3 scripts/archive-v6.py` 순서로 실행합니다. 공개 전에는 새 코드와 ZIP의 민감 정보 검사를 별도로 수행하세요.

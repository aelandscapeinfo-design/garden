## 실행 검사

- 단위 검사 45개 통과: 기존 39개와 V6의 기하 차이·3개 구조 변형·LOD·뿌리 기준점·저장 검증 6개입니다.
- 브라우저 27개 고유 시나리오 통과: art/composition/garden의 18개와 materials-v6/zones의 9개를 파일 묶음별로 검사했습니다. 단일 27개 연속 실행을 뜻하지 않습니다.
- 독립 실행 HTML에서 추가 브라우저 4개를 통과했습니다. 신규 12개 자산의 화단 삭제 → 대기함 → undo/redo → 저장/새로고침 → JSON 내보내기에서 자산 ID·버전·seed·계절을 보존했습니다.
- 제공하는 게임 HTML은 실제 서버에서 검사한 HTML과 SHA256이 같습니다. PNG 내보내기는 편집 오버레이를 제외하며 V5 저장 슬롯을 덮어쓰지 않습니다.
- 실행 조건: Linux, Node.js 24.19.0, Chromium 154.0.8037.57. 모바일은 390 × 844 터치 에뮬레이션입니다. 실제 휴대폰·Safari·Windows 실행기를 검증했다고 주장하지 않습니다.

요약은 evidence/v6/test-summary.json, 기하·참고 자료는 asset-manifest.json, 독립 HTML 확인 결과는 standalone-smoke.json에 있습니다. 내부 작업 기록과 프롬프트는 배포 자료에 포함하지 않습니다.

## 실제 수량과 형태 검수 상태

식물 카탈로그 19개 = 기존 7 + 신규 12. 현재 V4 미술 프로필에서 배치 가능한 것은 16개 = 기존 4 + 신규 12입니다. 신규 실제 자산 12개, 구별되는 형태 12개, 각 3개 구조 변형으로 총 36개 구조 변형, 신규 단순 색상 카탈로그 변형 0개입니다. 개체별 미세 색 편차를 새 수종으로 세지 않습니다.

36종 완성본이 아닙니다. 36개 신규 자산 목표까지 24개가 남았습니다. 현재 자산은 형태 예시이며 특정 품종 재현이나 전체 사진 대조 검수 완료 자산이 아닙니다. 관목 잎 밀도, 잎 세부 구조, 양치류 소엽, 그라스 꽃차례를 더 조정하고 자료와 대조해야 합니다. 성숙 크기·입지·내한성·식재 적합성을 검증한 DB는 없습니다.

## 실제 화면

전후 재질 샘플은 동일한 6 × 6 m 공간, 저장 카메라·조명·1440 × 960 브라우저에서 PNG로 내보냈습니다. material-samples.png와 materials-before-v5.png가 비교 쌍입니다. contact-sheet.png는 게임의 실제 자산 렌더이며 카드별 확대율이 다릅니다. 같은 배율의 전체 표본은 plant-specimens.png와 예제 JSON에서 비교할 수 있습니다. 4 × 3 배열의 간격은 가로 2.15 m, 세로 2.2 m이며 실제 권장 식재 간격이 아닙니다.

색 맵은 sRGB, 높이 맵은 선형 데이터, UV는 세계 좌표 1 m 기준입니다. bump와 줄눈의 normal 변화는 셰이딩이며 실제 보행면이나 식재 높이의 displacement가 아닙니다. 외부 사진이나 타사 메시·텍스처를 포함하지 않습니다. 참고 문서는 읽었지만 일부 사진은 접근 제한으로 대조하지 못했습니다.

## 성능 실측

다른 브라우저 검사를 마친 뒤 별도 브라우저의 SwiftShader 소프트웨어 렌더러에서 고정 카메라로 2회 워밍업 후 12회 렌더/readback 루프를 측정했습니다.

| 50 | 113 | 68916 | 166.6 | 183.4 | 6 |

모든 장면이 30fps 목표에 미달했습니다. 실제 휴대폰 FPS·순수 GPU 시간·매 프레임 그림자 갱신 비용을 뜻하지 않습니다. 최대 300개는 저장/배치 상한이며 성능 보장이 아닙니다. performance.json의 가져오기 시간은 데이터 가져오기와 카메라 대기 시간으로, 첫 GPU 프레임 완료 시간과는 구분합니다. 텍스처 bytes는 표면 참조의 추정치이며 전체 GPU/프로세스 메모리를 포함하지 않습니다.

별도 브라우저에서 2회 워밍업 뒤 6회 장면 왕복을 하고 실제 렌더/readback 후 집계한 geometry/texture/prototype 수는 안정적이었습니다. 초기 비동기 샘플도 원본 데이터에 함께 보존했습니다. 이 검사는 장시간 heap leak 부재를 증명하지 않습니다. 실제 기기 성능과 30fps 목표는 추가 검증·최적화가 필요합니다.

공개용 패키징 후 공개용 복사본에서 단위 검사 45개와 빌드를 재실행했고, 검증한 게임 HTML과 SHA256이 일치함을 확인했습니다.
